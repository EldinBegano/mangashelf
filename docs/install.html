Install

Get the files from the latest release on GitHub. It takes about a minute.

Firefox, Floorp, LibreWolfUpdates itself

  1. Download mangashelf-<version>-firefox.xpi.
  2. Open about:addons, click the gear icon, choose Install Add-on From File… and pick the file.
  3. Pin it to the toolbar from the puzzle-piece menu.

Regular Firefox only installs add-ons signed by Mozilla. Floorp and LibreWolf don't need that.

Chrome, Brave, EdgeTells you when an update is out

  1. Download mangashelf-<version>-chrome.zip and unzip it into a folder you keep.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick that folder.

To update, unzip the new version over the same folder and click the reload icon on mangashelf. Your settings stay.

Private windowsOptional

In Firefox and Floorp, open about:addons, select mangashelf and set Run in Private Windows to Allow. Downloads from private windows stay out of normal windows and your download history.
